Foreground service demonstration

This recording shows Mobile Pet running on a real Android device. The user starts the floating pet, interacts with it over another app, and stops it. The special-use foreground service keeps this visible, user-initiated feature running while enabled.

Some system and browser areas are obscured for privacy. The demonstrated app behavior has not been fabricated.
